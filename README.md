## How to Run a Program

1. Make sure a C++ compiler is installed (for example, GCC or MinGW).
2. Open a terminal in the repository directory.
3. Compile a source file:

   ```bash
   g++ "Variables.cpp" -o variables
   ```

4. Run the compiled program:

   **Windows**
   ```powershell
   .\variables.exe
   ```

   **Linux / macOS**
   ```bash
   ./variables
   ```

Replace `Variables.cpp` with the source file you want to practise. Some files may need their actual filename or extension checked before compiling.
